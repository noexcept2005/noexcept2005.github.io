# JackalClient display font

Barlow Condensed ExtraBold by Jeremy Tribby, locally hosted under the SIL Open Font License 1.1; see `OFL.txt`.

Source: https://github.com/google/fonts/tree/main/ofl/barlowcondensed

The original font binary is unmodified. Chinese text uses the existing system-font fallback. No game font is included.
